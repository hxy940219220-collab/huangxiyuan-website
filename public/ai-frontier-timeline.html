AI 模型与 Agent
发展时间线

不把更新日志当新闻列表，而是观察能力边界如何迁移：模型从单轮回答走向长周期执行，Agent 产品则开始围绕 runtime、状态、记忆、工具与恢复机制建立真正的系统差异。

2025.09—2026.07 17 个官方节点 更新于 2026.07.19 仅采用一手来源
SIGNAL 01

能力进入长周期

竞争焦点从回答质量继续向任务持续时间、上下文保持、并行协作和完成判断迁移。

SIGNAL 02

Runtime 成为产品层

Agent loop、状态恢复、记忆检索和工具权限不再只是工程实现，而直接决定用户信任。

SIGNAL 03

Harness 决定可交付性

更强模型仍需要目标、约束、验证器、反馈与人工确认，才能把能力稳定转成产品结果。

Reading notes

关于时间：日期优先使用官方发布页或 GitHub Release 的发布日期；只有月份的节点保留月级精度，不推测具体日期。

关于判断：“产品判断”不是官方结论，而是我基于发布事实做的产品侧推论，用来连接模型能力、Agent 机制与实际体验设计。

关于更新：这不是追求全量的新闻数据库，而是一份持续维护的能力迁移记录。新节点只有在存在一手来源、且对产品设计有实质影响时才会加入。
